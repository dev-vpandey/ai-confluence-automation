# Release Notes — v1.1.0

**Release date:** 2026-05-11
**Status:** Production Ready
**Audience:** Engineers and data practitioners using the `confluence-automation` Claude Code skill

---

## Summary

Expands the `confluence-automation` skill from a single-template tool to a full typed-template system covering 6 page types, each backed by a reference file that enforces section structure and placeholder rules. Restructures backend documentation from a flat `docs/` directory into an organized `documentation/` hierarchy. Fixes three reliability bugs: a missing CSRF header that caused Confluence to silently reject file attachments, a hardcoded clone path in `refresh-auth`, and an incorrect Python module path in `cf`.

**Impact:** Low — no existing commands or auth flows changed
**Breaking changes:** None
**Migration required:** No
**Action required:** None

---

## What's new

### Typed template system for `confluence-automation`

The skill now ships 6 HTML templates and 7 reference files. For any typed page (AI Win Story, Architecture, Data Flow, Infra Flow, PRD, User Guide), the skill reads the matching reference file first to identify required sections and placeholders, then fills the HTML template — no sections skipped, no placeholders left empty.

**Who benefits:** Anyone using the skill to create structured Confluence pages

### Structured `documentation/` directory

Backend docs reorganized from a flat `docs/` directory into a hierarchy:

```
documentation/
  USER-GUIDE.md
  architecture/
    DESIGN-DOC.md
    PRD.md
    diagrams/
      confluence-architecture.drawio / .png
      how-it-works.drawio / .png
```

`QUICK_REFERENCE.md` content folded into `documentation/USER-GUIDE.md`. Flat `docs/` removed.

**Who benefits:** Engineers onboarding to or contributing to the project

## Fixed

### File attachments rejected by Confluence (403)

**Problem:** `src/attach_file.py` omitted the `X-Atlassian-Token: nocheck` header required by Confluence for multipart POST requests, causing all attachment uploads to fail with 403.
**Fix:** Header added to both create and update paths.

### File descriptor leak in `attach_file.py`

**Problem:** File handle on the update path was never closed, causing resource leaks on repeated attachment calls.
**Fix:** File open wrapped in a `with` context manager.

### `refresh-auth` fails outside original clone directory

**Problem:** Script hardcoded `cd ~/bitbucket/ai-data-confluence-automation`, breaking on any other clone location.
**Fix:** Replaced with `$(dirname "${BASH_SOURCE[0]}")` — script now resolves its own directory at runtime.

### `cf` invokes wrong Python module path

**Problem:** `cf` called `python confluence.py` but the module lives at `src/confluence.py`.
**Fix:** Path corrected to `python src/confluence.py`.

## Changed

### `SKILL.md` — full rewrite

**Before:** Partial commands, incomplete template table, no typed-page workflow.
**After:** Consolidated commands, table mapping all 6 page types to HTML template + reference file, step-by-step typed-page workflow, execution checklist.
**Why:** Skill had grown piecemeal; new reference system required a coherent single-entry-point doc.

### `requirements.txt`

**Before:** Included `pyyaml>=6.0`.
**After:** Removed — not used by any module.
**Why:** Reduces install surface; no functional impact.
