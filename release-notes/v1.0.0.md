## ✨ Added

### Core Scripts

**`src/confluence_page.py`** — Main CLI script  
- `create` — Create pages with optional parent-child relationships
- `update` — Update existing pages with automatic version tracking
- `search` — Search pages across all or specific spaces
- Auto-escape HTML special characters (ampersand fix)
- Cookie age check — warns when session > 12 hours old

**`src/confluence.py`** — Legacy OOP-style script  
- Alternative implementation with class-based structure
- Backwards-compatible entry point via `cf` wrapper

**`src/attach_file.py`** — File attachment  
- Attach any file type to a Confluence page
- Auto-detection of existing attachments (update vs create)

**`src/attach_image.py`** — Image attachment  
- Attach images with embed code generation
- Supported formats: PNG, JPG, JPEG, GIF, SVG

**`src/convert_drawio_to_png.py`** — Diagram conversion  
- Convert `.drawio` diagrams to PNG via Playwright/Chromium
- Batch conversion mode (`--batch`)

**`src/refresh_cookies.py`** — Cookie management  
- Guided mode: walks through Chrome DevTools extraction
- Manual mode: direct cookie input

### Authentication

- Cookie-based auth via `~/.confluence-session`
- `./refresh-auth` wrapper script for easy refresh
- Guided (`--guided`) and manual (`--manual`) modes
- Cookie age validation with user prompts

## 📦 Migration Guide

### First-Time Setup

```bash
git clone <repo-url>
cd ai-data-confluence-automation
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
playwright install chromium
./refresh-auth --guided
```

## 📋 Known Issues

- `./refresh-auth` and `cf` scripts contain hardcoded `~/bitbucket/` path — must be run from repo root to work correctly
- Cookie auto-extraction (`./refresh-auth` with no flags) is not functional — use `--guided` or `--manual`
