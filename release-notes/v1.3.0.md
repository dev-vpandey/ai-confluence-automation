# Release Notes — v1.3.0

**Release date:** 2026-05-23
**Status:** Production Ready
**Audience:** Engineers and data practitioners using the `confluence-automation` Claude Code skill

---

## Summary

Moves all hardcoded configuration out of source files into a central `config.yaml`. Previously, the Confluence base URL, session file path, and HTTP timeouts were scattered across six source files with no way to change them without editing code. Now they live in one place.

**Impact:** Low — no commands, auth flow, or page operations changed
**Breaking changes:** None
**Migration required:** No
**Action required:** Optional — copy `config.example.yaml` to `config.yaml` if you want to override any defaults

---

## What's new

### `config.yaml` for runtime configuration

A new `src/config.py` module loads settings from `config.yaml` at the repo root on startup. If the file doesn't exist, everything falls back to the same hardcoded defaults that were there before — so existing setups are unaffected.

To create your local config:

```bash
cp config.example.yaml config.yaml
```

Settings you'd actually change:

| Setting | Default | When to change |
|---------|---------|----------------|
| `confluence.base_url` | `https://confluence.ops.expertcity.com` | Pointing at a different instance |
| `confluence.session_file` | `~/.confluence-session` | Want cookies stored elsewhere |
| `timeouts.health_check` | `5` | Slow network |
| `timeouts.search` | `10` | Slow network |
| `timeouts.create_page` | `30` | Slow network |

`config.yaml` is gitignored — your local values won't end up in commits. `config.example.yaml` is the reference template and is tracked.

`CONFLUENCE_TOKEN` stays in `~/.zshrc`, same as before. Auth is not in this file.

### Consistent hostname resolution

All six source files that previously embedded `confluence.ops.expertcity.com` as a bare string now derive the hostname from `BASE_URL` via `urlparse`. If you change `base_url` in `config.yaml`, cookie domains, session URLs, and instructional messages all update automatically.

## Changed

### Source files

All configuration constants removed from source and replaced with imports from `src/config.py`:

- `src/confluence_page.py` — `BASE_URL`, `SESSION_FILE`, cookie domain
- `src/confluence.py` — `BASE_URL`, `SESSION_FILE`, three HTTP timeouts
- `src/refresh_cookies.py` — `BASE_URL`, `SESSION_FILE`, hostname in instructional strings
- `src/attach_image.py` — cookie domain

### Dependencies

- `pyyaml>=6.0` added to `requirements.txt`

### Documentation

- `README.md` — Configuration section added; setup step added; directory structure updated
- `documentation/USER-GUIDE.md` — Configuration section added; Quick Start and Limitations updated; v1.3 changelog entry added
- `documentation/adr/0002-config-yaml-for-runtime-settings.md` — new ADR documenting the choice of `config.yaml` over env vars or `python-dotenv`

## Known issues
